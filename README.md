# Sorting-Algorithms

Visualized Sorting Algorithms is a small website which you can use to test and compare sorting algorithms with custom parameters. I made with project to improve my JavaScript skills and to kill time.

## Documentation

Tailwind classes are added to HTML elements in a specific order to make development easier. This order is:

1. Flexbox and alignment
2. Padding margin and gap
3. Border and rounding
4. Colors
5. Typography
6. Other
7. Custom CSS classes
